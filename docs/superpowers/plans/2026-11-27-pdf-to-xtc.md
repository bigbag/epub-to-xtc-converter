# PDF → XTC/XTCH Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert PDF files to XTC/XTCH for Xteink e-readers in both the Node CLI and the browser app, with fit/trim page mapping and a layout-preserving zoom & split mode.

**Architecture:** A shared DOM-free core (`web/pdf-core.js`) implements layout math, trim detection, TOC mapping, and the pdf.js document-source orchestration via an injected canvas factory. Two thin adapters (Node: `cli/pdf-renderer.js`; browser: `web/pdf-source.js`) supply pdf.js + canvas. Everything downstream (dither, encode, container) is reused unchanged. The EPUB/CREngine path is not refactored.

**Tech Stack:** pdfjs-dist **6.5.438** (pinned, legacy build, Apache-2.0), @napi-rs/canvas ^1.2.1 (Node canvas, MIT), Node `node --test`, vanilla JS browser app (no build step; jsDelivr CDN).

**Spec:** `docs/superpowers/specs/2026-11-27-pdf-to-xtc-design.md`

## Global Constraints

- pdfjs-dist version **6.5.438** exactly, identical in `cli/package.json` and the web CDN base URL `https://cdn.jsdelivr.net/npm/pdfjs-dist@6.5.438`.
- CLI Node engine floor raised to `>=22.13.0` (pdfjs-dist 6.x requirement; Node 18 is EOL).
- Web app keeps its no-build-step pattern: classic `<script>` tags + dynamic `import()` for pdf.js ESM from CDN.
- EPUB conversion and optimizer behavior unchanged; `stable-pages.test.js` must keep passing. `code-layout.test.js` is a manual script (font-path argument) — never include it in `node --test` runs.
- Zoom range **[1.0, 3.0]**; trim background threshold: pixel is background when **all RGB channels ≥ 250**; safety padding **2 detection pixels** per side; trim detection render longest side **200 px**.
- Tiles emitted **row-major**; a single tile is **centered** on the white device canvas; multi-tile grids place tiles **top-left** with white padding on right/bottom edges.
- Guards: render canvas side **≤ 8192 px**; total device pages **≤ 65535** (XTC uint16 fields).
- XTC field capacities (byte-safe UTF-8, null-terminated): title **127 bytes**, author **63 bytes**, chapter title **79 bytes**.
- Device presets: X4 480×800, X3 528×792 (existing `DEVICES` maps, unchanged).
- pdf.js cleanup is `await loadingTask.destroy()` (the object returned by `getDocument`); `PDFDocumentProxy.destroy` does not exist in 6.x.
- Verified Node recipe (probe against the example PDF): `getDocument({ data, useWorkerFetch: false, isEvalSupported: false })` — Node factories and package assets (standard_fonts/cmaps/wasm) auto-resolve; no custom CanvasFactory needed. Browser must set `workerSrc`, `standardFontDataUrl`, `cMapUrl` (+`cMapPacked: true`), `wasmUrl` to the pinned CDN paths.

## Review Focus

Inputs/conditions the spec implies that are most likely to bite a real user — each is pinned by a test in the owning task:

1. **Rotated PDF pages (`/Rotate 90/270`)** must render upright using pdf.js viewport dimensions (not raw MediaBox) — Task 5 (`rotateLast` fixture asserts swapped layout dims).
2. **Non-ASCII / overlong titles** (CJK chapter names are common in PDFs) must never overflow fixed XTC fields or split UTF-8 sequences — Task 3 (CJK truncation tests).
3. **Blank / all-white pages with trim enabled** must fall back to the full page box, never a degenerate/negative box — Task 1 (blank bitmap test) + Task 5 (blank fixture test).
4. **Password-protected / corrupt PDFs** must produce a friendly error, write no output file, and let a batch continue — Task 2 (`mapPdfError` units) + Task 6 (corrupt-file e2e).
5. **Font-less runs:** PDF-only input must convert without `font.path`; a mixed EPUB+PDF set without a font must fail validation with the clear font message — Task 6 (CLI spawn tests).

```js
/**
 * Shared PDF conversion logic (DOM-free).
 * Used by cli/pdf-renderer.js (Node) and web/pdf-source.js (browser).
 * Dual export: CommonJS via module.exports, browser global via window.PdfCore.
 */
(function (root, factory) {
    const api = factory();
    if (typeof module !== 'undefined' && module.exports) module.exports = api;
    if (root) root.PdfCore = api;
})(typeof window !== 'undefined' ? window : globalThis, function () {
    'use strict';

    /** Bounding box of non-background pixels. Blank page -> full bounds. */
    function detectContentBox(rgba, width, height, threshold, padding) {
        if (threshold === undefined) threshold = 250;
        if (padding === undefined) padding = 2;
        let minX = width, minY = height, maxX = -1, maxY = -1;
        for (let y = 0; y < height; y++) {
            for (let x = 0; x < width; x++) {
                const o = (y * width + x) * 4;
                if (rgba[o] < threshold || rgba[o + 1] < threshold || rgba[o + 2] < threshold) {
                    if (x < minX) minX = x;
                    if (x > maxX) maxX = x;
                    if (y < minY) minY = y;
                    if (y > maxY) maxY = y;
                }
            }
        }
        if (maxX < 0) return { x: 0, y: 0, w: width, h: height };
        const x = Math.max(0, minX - padding);
        const y = Math.max(0, minY - padding);
        const right = Math.min(width - 1, maxX + padding);
        const bottom = Math.min(height - 1, maxY + padding);
        return { x, y, w: right - x + 1, h: bottom - y + 1 };
    }

    /**
     * Unified fit/trim/zoom layout. All dims in PDF units except screen W/H (px).
     * Returns render-canvas dims (rw/rh), content rect (cx/cy/cw/ch) within it,
     * and the row-major tile grid.
     */
    function computeLayout(vw, vh, W, H, opts) {
        opts = opts || {};
        const zoom = opts.zoom === undefined ? 1 : opts.zoom;
        const box = opts.box || { x: 0, y: 0, w: vw, h: vh };
        const base = Math.min(W / box.w, H / box.h);
        const scale = base * zoom;
        const rw = Math.round(vw * scale);
        const rh = Math.round(vh * scale);
        const cx = Math.round(box.x * scale);
        const cy = Math.round(box.y * scale);
        const cw = Math.round(box.w * scale);
        const ch = Math.round(box.h * scale);
        const cols = Math.ceil(cw / W);
        const rows = Math.ceil(ch / H);
        return { scale, rw, rh, cx, cy, cw, ch, cols, rows, count: cols * rows, screenW: W, screenH: H };
    }

    /** Source rect of tile i within the full-page render canvas (row-major). */
    function tileSourceRect(layout, i) {
        const col = i % layout.cols;
        const row = Math.floor(i / layout.cols);
        return {
            x: layout.cx + col * layout.screenW,
            y: layout.cy + row * layout.screenH,
            w: Math.min(layout.screenW, layout.cw - col * layout.screenW),
            h: Math.min(layout.screenH, layout.ch - row * layout.screenH)
        };
    }

    /** Single tile: centered. Multi-tile grid: top-left. */
    function tileDestOffset(layout) {
        if (layout.count === 1) {
            return {
                dx: Math.floor((layout.screenW - layout.cw) / 2),
                dy: Math.floor((layout.screenH - layout.ch) / 2)
            };
        }
        return { dx: 0, dy: 0 };
    }

    return { detectContentBox, computeLayout, tileSourceRect, tileDestOffset };
});
```

```js
    /** Depth-first flatten of pdf.js getOutline() items. */
    function flattenOutline(items) {
        const out = [];
        (function walk(list) {
            if (!Array.isArray(list)) return;
            for (const item of list) {
                if (!item) continue;
                out.push({ title: item.title || '', dest: item.dest });
                if (item.items) walk(item.items);
            }
        })(items);
        return out;
    }

    function prefixSums(counts) {
        const sums = [0];
        for (let i = 0; i < counts.length; i++) sums.push(sums[i] + counts[i]);
        return sums;
    }

    /** entries: [{title, page}] with page = 0-based PDF page or null. */
    function mapTocToDevices(entries, tileCounts) {
        const sums = prefixSums(tileCounts);
        const out = [];
        for (const e of entries) {
            if (!Number.isInteger(e.page) || e.page < 0 || e.page >= tileCounts.length) continue;
            out.push({ title: e.title, page: sums[e.page] });
        }
        return out;
    }

    /** Binary search: device page index -> {pdfPage, tile}. */
    function locateTile(sums, deviceIndex) {
        let lo = 0, hi = sums.length - 2;
        while (lo < hi) {
            const mid = (lo + hi + 1) >> 1;
            if (sums[mid] <= deviceIndex) lo = mid; else hi = mid - 1;
        }
        return { pdfPage: lo, tile: deviceIndex - sums[lo] };
    }

    function validatePdfOptions(opts) {
        const errors = [];
        opts = opts || {};
        if (opts.zoom !== undefined) {
            if (typeof opts.zoom !== 'number' || !Number.isFinite(opts.zoom) || opts.zoom < 1 || opts.zoom > 3) {
                errors.push('pdf.zoom must be a number between 1.0 and 3.0');
            }
        }
        if (opts.trimMargins !== undefined && typeof opts.trimMargins !== 'boolean') {
            errors.push('pdf.trimMargins must be a boolean');
        }
        return errors;
    }

    function mapPdfError(err) {
        const name = err && err.name;
        if (name === 'PasswordException') return new Error('Password-protected PDFs are not supported');
        if (name === 'InvalidPDFException' || name === 'MissingPDFException') return new Error('Invalid or corrupt PDF file');
        return err;
    }

    function assertRenderLimits(rw, rh) {
        if (rw > 8192 || rh > 8192) throw new Error('PDF render size exceeds 8192px; lower the zoom');
    }

    function assertPageCount(n) {
        if (n > 65535) throw new Error('PDF produces more than 65535 device pages; lower the zoom');
    }
```

```js
'use strict';
/**
 * Minimal PDF fixture builder for tests. No dependencies.
 * All content is ASCII, so string length === byte length (latin1).
 */
function buildPdfFixture(opts) {
    opts = opts || {};
    const pageCount = opts.pageCount || 3;
    const width = opts.width || 612;
    const height = opts.height || 792;
    const withOutline = opts.outline !== false && pageCount >= 2;
    const rotateLast = !!opts.rotateLast;
    const blank = !!opts.blank;

    let next = 1;
    const catalogNum = next++;
    const pagesNum = next++;
    const fontNum = next++;
    const pageNums = [], contentNums = [];
    for (let i = 0; i < pageCount; i++) { pageNums.push(next++); contentNums.push(next++); }
    let outlineNum = 0, firstNum = 0, secondNum = 0;
    if (withOutline) { outlineNum = next++; firstNum = next++; secondNum = next++; }

    const objects = [];
    objects.push({ num: catalogNum, body: `<< /Type /Catalog /Pages ${pagesNum} 0 R${withOutline ? ` /Outlines ${outlineNum} 0 R` : ''} >>` });
    objects.push({ num: pagesNum, body: `<< /Type /Pages /Kids [${pageNums.map(n => `${n} 0 R`).join(' ')}] /Count ${pageCount} >>` });
    objects.push({ num: fontNum, body: '<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica >>' });
    for (let i = 0; i < pageCount; i++) {
        const rotate = rotateLast && i === pageCount - 1 ? ' /Rotate 90' : '';
        objects.push({ num: pageNums[i], body: `<< /Type /Page /Parent ${pagesNum} 0 R /MediaBox [0 0 ${width} ${height}]${rotate} /Resources << /Font << /F1 ${fontNum} 0 R >> >> /Contents ${contentNums[i]} 0 R >>` });
        const stream = blank ? '' : `BT /F1 24 Tf 72 720 Td (Page ${i + 1}) Tj ET\n0 0 0 rg 72 72 468 600 re f\n`;
        objects.push({ num: contentNums[i], body: `<< /Length ${stream.length} >>\nstream\n${stream}endstream` });
    }
    if (withOutline) {
        objects.push({ num: outlineNum, body: `<< /Type /Outlines /First ${firstNum} 0 R /Last ${secondNum} 0 R /Count 2 >>` });
        objects.push({ num: firstNum, body: `<< /Title (Chapter One) /Parent ${outlineNum} 0 R /Next ${secondNum} 0 R /Dest [${pageNums[0]} 0 R /XYZ 0 ${height} 0] >>` });
        objects.push({ num: secondNum, body: `<< /Title (Chapter Two) /Parent ${outlineNum} 0 R /Prev ${firstNum} 0 R /Dest [${pageNums[1]} 0 R /XYZ 0 ${height} 0] >>` });
    }

    objects.sort((a, b) => a.num - b.num);
    let out = '%PDF-1.4\n';
    const offsets = {};
    for (const obj of objects) {
        offsets[obj.num] = out.length;
        out += `${obj.num} 0 obj\n${obj.body}\nendobj\n`;
    }
    const xrefOffset = out.length;
    const maxNum = objects[objects.length - 1].num;
    out += `xref\n0 ${maxNum + 1}\n0000000000 65535 f \n`;
    for (let n = 1; n <= maxNum; n++) out += `${String(offsets[n]).padStart(10, '0')} 00000 n \n`;
    out += `trailer\n<< /Size ${maxNum + 1} /Root ${catalogNum} 0 R >>\nstartxref\n${xrefOffset}\n%%EOF\n`;
    return new Uint8Array(Buffer.from(out, 'latin1'));
}

module.exports = { buildPdfFixture };
```

```js
/**
 * Node adapter: pdf.js + @napi-rs/canvas -> PDF document source.
 * Verified against pdfjs-dist 6.5.438: Node factories and package assets
 * (standard_fonts, cmaps, wasm) auto-resolve; no custom CanvasFactory needed.

const fs = require('fs');
const path = require('path');
const { createCanvas: napiCreateCanvas } = require('@napi-rs/canvas');
const PdfCore = require('../web/pdf-core.js');

let pdfjsPromise = null;
function loadPdfjs() {
    if (!pdfjsPromise) pdfjsPromise = import('pdfjs-dist/legacy/build/pdf.mjs');
    return pdfjsPromise;
}

async function openPdf(data) {
    const pdfjs = await loadPdfjs();
    const task = pdfjs.getDocument({ data, useWorkerFetch: false, isEvalSupported: false });
    try {
        const doc = await task.promise;
        return { doc, task };
    } catch (err) {
        await task.destroy().catch(() => {});
        throw PdfCore.mapPdfError(err);
    }
}

function createCanvas(w, h) {
    const canvas = napiCreateCanvas(w, h);
    return { canvas, context: canvas.getContext('2d') };
}

async function renderPageToCanvas(doc, pageNumber, scale) {
    const page = await doc.getPage(pageNumber);
    const viewport = page.getViewport({ scale });
    const { canvas, context } = createCanvas(Math.max(1, Math.round(viewport.width)), Math.max(1, Math.round(viewport.height)));
    context.fillStyle = '#ffffff';
    context.fillRect(0, 0, canvas.width, canvas.height);
    await page.render({ canvasContext: context, viewport }).promise;
    return { canvas, context, viewport };
}

module.exports = { loadPdfjs, openPdf, createCanvas, renderPageToCanvas };
```

```js
     * Build a device-page document source from an open pdf.js document.
     * createCanvas(w, h) -> {canvas, context} is injected (DOM or @napi-rs/canvas).

    async function createSource(opts) {
        const doc = opts.doc;
        const loadingTask = opts.loadingTask;
        const createCanvas = opts.createCanvas;
        const width = opts.width;
        const height = opts.height;
        const trimMargins = !!opts.trimMargins;
        const zoom = opts.zoom === undefined ? 1 : opts.zoom;
        const errors = validatePdfOptions({ zoom, trimMargins });
        if (errors.length) throw new Error(errors.join('; '));

        const layouts = [];
        const tileCounts = [];
        for (let p = 1; p <= doc.numPages; p++) {
            const page = await doc.getPage(p);
            const vp = page.getViewport({ scale: 1 });
            let box = null;
            if (trimMargins) {
                const ds = 200 / Math.max(vp.width, vp.height);
                const dw = Math.max(1, Math.round(vp.width * ds));
                const dh = Math.max(1, Math.round(vp.height * ds));
                const det = createCanvas(dw, dh);
                det.context.fillStyle = '#ffffff';
                det.context.fillRect(0, 0, dw, dh);
                await page.render({ canvasContext: det.context, viewport: page.getViewport({ scale: ds }) }).promise;
                const px = detectContentBox(det.context.getImageData(0, 0, dw, dh).data, dw, dh);
                box = { x: px.x / ds, y: px.y / ds, w: px.w / ds, h: px.h / ds };
            }
            const layout = computeLayout(vp.width, vp.height, width, height, { zoom, box });
            assertRenderLimits(layout.rw, layout.rh);
            layouts.push(layout);
            tileCounts.push(layout.count);
        }
        const sums = prefixSums(tileCounts);
        const pageCount = sums[sums.length - 1];
        assertPageCount(pageCount);

        const entries = [];
        const outline = await doc.getOutline();
        for (const item of flattenOutline(outline)) {
            let page = null;
            try {
                const dest = typeof item.dest === 'string' ? await doc.getDestination(item.dest) : item.dest;
                if (Array.isArray(dest) && dest[0]) page = await doc.getPageIndex(dest[0]);
            } catch (e) { page = null; }
            entries.push({ title: item.title, page });
        }
        const toc = mapTocToDevices(entries, tileCounts);

        const meta = await doc.getMetadata().catch(() => null);
        const info = {
            title: (meta && meta.info && meta.info.Title) || '',
            author: (meta && meta.info && meta.info.Author) || ''
        };

        let last = null; // cache: consecutive tiles of one PDF page reuse the render
        async function renderPage(deviceIndex) {
            if (deviceIndex < 0 || deviceIndex >= pageCount) {
                throw new Error('Device page index out of range: ' + deviceIndex);
            }
            const loc = locateTile(sums, deviceIndex);
            const layout = layouts[loc.pdfPage];
            if (!last || last.pdfPage !== loc.pdfPage) {
                const page = await doc.getPage(loc.pdfPage + 1);
                const viewport = page.getViewport({ scale: layout.scale });
                const c = createCanvas(layout.rw, layout.rh);
                c.context.fillStyle = '#ffffff';
                c.context.fillRect(0, 0, layout.rw, layout.rh);
                await page.render({ canvasContext: c.context, viewport }).promise;
                last = { pdfPage: loc.pdfPage, context: c.context };
            }
            const rect = tileSourceRect(layout, loc.tile);
            const tile = last.context.getImageData(rect.x, rect.y, rect.w, rect.h);
            const out = createCanvas(width, height);
            out.context.fillStyle = '#ffffff';
            out.context.fillRect(0, 0, width, height);
            const off = tileDestOffset(layout);
            out.context.putImageData(tile, off.dx, off.dy);
            return new Uint8ClampedArray(out.context.getImageData(0, 0, width, height).data);
        }

        return {
            pageCount, info, toc, layouts, renderPage,
            destroy: () => loadingTask.destroy()
```

```js
/**
 * Convert a single PDF to XTC/XTCH (mirrors convertEpub's pipeline).
 */
async function convertPdf(inputPath, outputPath, settings, progressCallback) {
    const { width, height, output, pdf } = settings;
    const isHQ = output.format === 'xtch';
    const bits = isHQ ? 2 : 1;

    const data = new Uint8Array(fs.readFileSync(inputPath));
    const source = await createNodePdfSource(data, {
        width, height, trimMargins: pdf.trimMargins, zoom: pdf.zoom
    });

    try {
        const pages = [];
        for (let i = 0; i < source.pageCount; i++) {
            let imageData = await source.renderPage(i);
            if (output.dithering) {
                imageData = applyDithering(imageData, width, height, bits, output.ditherStrength);
            }
            if (output.negative) applyNegative(imageData);
            pages.push(isHQ ? encodeXTH(imageData, width, height) : encodeXTG(imageData, width, height));
            if (progressCallback) progressCallback(i + 1, source.pageCount);
        }

        const metadata = {
            title: source.info.title || path.basename(inputPath, path.extname(inputPath)),
            author: source.info.author || ''
        };
        const container = buildXTCContainer(pages, metadata, source.toc, width, height, isHQ);
        fs.writeFileSync(outputPath, container);
        return { outputPath, pageCount: source.pageCount, format: output.format };
    } finally {
        await source.destroy();
    }
}
```

```js
/**
 * Browser adapter: pdf.js (pinned CDN, legacy ESM build) + DOM canvas.
 * Exposes window.PdfWeb. Requires pdf-core.js loaded first.
 * Safari 14 lacks module workers; pdf.js falls back to its main-thread
 * fake worker automatically (slower, functional).
 */
(function (global) {
    'use strict';

    var PDFJS_BASE = 'https://cdn.jsdelivr.net/npm/pdfjs-dist@6.5.438';
    var libPromise = null;

    function loadPdfjs() {
        if (!libPromise) {
            libPromise = import(PDFJS_BASE + '/legacy/build/pdf.min.mjs').then(function (lib) {
                lib.GlobalWorkerOptions.workerSrc = PDFJS_BASE + '/legacy/build/pdf.worker.min.mjs';
                return lib;
            });
        }
        return libPromise;
    }

    function createCanvas(w, h) {
        var canvas = document.createElement('canvas');
        canvas.width = w;
        canvas.height = h;
        return { canvas: canvas, context: canvas.getContext('2d') };
    }

    async function createSource(data, opts) {
        var lib = await loadPdfjs();
        var task = lib.getDocument({
            data: data,
            standardFontDataUrl: PDFJS_BASE + '/standard_fonts/',
            cMapUrl: PDFJS_BASE + '/cmaps/',
            cMapPacked: true,
            wasmUrl: PDFJS_BASE + '/wasm/'
        });
        var doc;
        try {
            doc = await task.promise;
        } catch (err) {
            await task.destroy().catch(function () {});
            throw global.PdfCore.mapPdfError(err);
        }
        try {
            return await global.PdfCore.createSource({
                doc: doc, loadingTask: task, createCanvas: createCanvas,
                width: opts.width, height: opts.height,
                trimMargins: opts.trimMargins, zoom: opts.zoom
            });
        } catch (err) {
            await task.destroy().catch(function () {});
            throw global.PdfCore.mapPdfError(err);
        }
    }

    global.PdfWeb = { loadPdfjs: loadPdfjs, createSource: createSource };
})(window);
```

```js
    pdfTrimMargins.checked = true;
    pdfTrimMargins.dispatchEvent(new Event('change'));
    await sleep(5000);
    check(totalPages > 0, 'Trim rebuild failed');

    // Export container sanity
    var xtc = await generateXTC(function() {});
    var magic = String.fromCharCode(xtc[0], xtc[1], xtc[2], xtc[3]);
    check(magic === 'XTC\0' || magic === 'XTCH', 'Bad container magic: ' + magic);
    var dv = new DataView(xtc.buffer, xtc.byteOffset, xtc.byteLength);
    check(dv.getUint16(6, true) === totalPages, 'Container page count mismatch');

    // Restore defaults
    pdfZoom.value = '1';
    pdfZoom.dispatchEvent(new Event('change'));
    pdfTrimMargins.checked = false;
    pdfTrimMargins.dispatchEvent(new Event('change'));
    console.log('PDF smoke OK');
})().catch(function(e) { console.error('PDF smoke FAILED:', e); });
```
